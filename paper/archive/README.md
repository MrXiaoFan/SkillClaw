# Paper Archive

This directory contains historical paper snapshots and LaTeX build outputs. It is preserved for
comparison and reproducibility, not as a daily editing area.

- `manuscript_snapshot_20260824/` — older manuscript snapshot
- `build_20260826/` — archived package build outputs
- `root_build_20260826/` — archived root-level build outputs

For current editing, use `paper/package_20260824/manuscript/`. Archive contents should not be
deleted merely because a newer draft exists; they document what earlier conclusions and builds
looked like.
