# Plans

`docs/plans/` 放“下一步做什么”，不放已经完成的实验原始结果。

## 当前主入口

- `work_plan_20260820.md`
  - 操作级工作计划
  - 说明阶段 0-3 的剩余任务、执行顺序、验收条件
- `research_roadmap_20260820.md`
  - 研究路线与论文对齐文档
  - 说明当前工程目标、学术目标、风险边界、阶段收束方式
- `benchmark_candidate_backlog.md`
  - 备选 benchmark / case 候选池

## 使用原则

- 想知道“现在下一步该做什么”，先看这里
- 想知道“已经做到了什么、有哪些证据”，去看 `reports/` 和 `docs/handoff/`
- 不要把实验结果表、阶段周报、临时排查笔记继续堆进 `plans/`
