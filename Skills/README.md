# Generated Skill Snapshot

This directory is not part of the upstream AMAP-ML/SkillClaw baseline.

It is a snapshot of the local SkillClaw skill pool used in the vulnerability
localization experiments. The snapshot is included so collaborators can
reproduce the same server-side skill catalog and compare SkillClaw proxy runs
against direct LLM runs.

Current snapshot:

- 35 skill directories
- `skill_stats.json` with local usage/feedback counters
- Main research domains: Linux binary vulnerability localization, firmware
  analysis, Cisco IOS-XE WebUI/WSMA analysis, IDA headless workflows, and
  SkillClaw self-inspection/retrieval diagnostics

Do not treat these files as upstream built-in SkillClaw skills. They are
research artifacts produced and curated during the extension work.
