# v1

## Summary

This revision preserves the parser-state-machine localization workflow and
strengthens exact CVE attribution behavior for benchmark-style outputs.

## What Changed

- Added explicit rules to avoid multi-CVE hedge lists when exact advisory-level
  evidence is missing.
- Separated localization confidence from exact CVE attribution confidence.
- Added an output policy that prefers `predicted_cves: []` and
  `cve_identity: uncertain` over speculative CVE naming.

## Intended Effect

- Preserve strong file/function/root-cause localization for libxml2 parser
  cases.
- Reduce `cve_calibration_miss` outcomes by making uncertainty explicit.
