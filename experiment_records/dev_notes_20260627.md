## Completed

The local repository was synchronized with Codeup `dev`, including the upstream
session-management commit `0459657 feat: add claude code session manage`.

Two experiment-framework commits were added after that:

- `c0f4f01 test: add experiment environment preflight check`
- `a665ba0 test: gate eval runner with preflight checks`

The new preflight path checks whether a VM experiment is ready before starting a
long Claude Code run. It verifies the case JSON, target source root, target
binary, ground-truth source files, Claude Code provider, and optionally the
SkillClaw `/healthz` and `/v1/skills` endpoints.

`run_eval_case.py` now supports `--preflight`. When enabled, it writes
`<run-id>-preflight.json`, includes the preflight result in the final record,
and stops before invoking Claude Code if the environment is wrong.
