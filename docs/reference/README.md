# Reference

`docs/reference/` 保存全局统一口径，不放案例专属笔记。

## 当前入口

- `extension_architecture.md`
  - 扩展工程的详细架构说明
- `extension_architecture_summary.md`
  - 面向汇报的一页摘要版
- `scoring_rubric.md`
  - 评分规则、判定标准、复用定义

## 建议阅读顺序

如果你要先理解工程结构：

1. `extension_architecture_summary.md`
2. `extension_architecture.md`
3. `scoring_rubric.md`

如果你要继续开发或排查结果：

1. `extension_architecture.md`
2. `scoring_rubric.md`
